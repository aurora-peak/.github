## Identity

<p align="center">
  <img src="https://raw.githubusercontent.com/aurora-peak/.github/main/profile/assets/aurora-peak-palette.png" alt="Aurora Peak color system: Deep Indigo #0F1A24, Slate Blue #314556, Pine Teal #3D6F6F, Aurora Teal #5AA7A1, Dusty Violet #7B6A89, Mist Gray #A7ADB5, Fog #F2F4F7, Snow #FFFFFF, Night #08111B." width="880">
</p>

The mark reads first as a mountain and second as an embedded **AP** monogram &mdash; the outer
silhouette forms the mountain and the **A**, and the interior negative space carves a river
that suggests the **P**. Type is Poppins for display, Inter for interface, and IBM Plex Mono
for technical detail.

Brand assets live in [`profile/assets`](https://github.com/aurora-peak/.github/tree/main/profile/assets).
